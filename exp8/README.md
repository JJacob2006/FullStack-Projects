## Project Overview

This is a full-stack web application demonstrating authentication and protected routes. The project consists of a Node.js/Express backend server that handles API requests and JWT-based authentication, along with a React frontend built with Vite that includes login functionality and protected pages. The frontend uses React Router for navigation between public and authenticated routes, while the backend manages user authentication tokens and secure API endpoints.

## Tools & Technologies Used

**Backend:**
- Express.js - Web framework
- Node.js - Runtime environment
- JWT (jsonwebtoken) - Token-based authentication
- Axios - HTTP client
- CORS - Cross-origin resource sharing
- dotenv - Environment variable management

**Frontend:**
- React - UI library
- Vite - Build tool and dev server
- React Router DOM - Client-side routing
- Axios - HTTP client
- ESLint - Code linting

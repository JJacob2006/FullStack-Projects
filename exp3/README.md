## About the Program
This project demonstrates a simple library management system built using front-end technologies. It allows users to add new books, search through existing books, and remove books dynamically.

The application uses HTML for structure, CSS for styling with a modern dark theme, and JavaScript for implementing logic such as state management, filtering, and DOM updates. It simulates CRUD operations (Create, Read, Delete) without a backend.

---

## Features
- Add new books with title and author  
- Search books in real-time  
- Remove books from the list  
- Dynamic UI updates without page reload  
- Clean and modern dark-mode interface  

---

## Approach

### 1. Structure (HTML)
- Input fields for title and author  
- Search bar for filtering books  
- Container for displaying book list  

### 2. Styling (CSS)
- Dark theme with gradient background  
- Card-based layout for books  
- Responsive and visually appealing UI  

### 3. Behavior (JavaScript)
- Books stored in an array (state management)  
- Event listeners for add, search, and remove actions  
- Dynamic rendering of book list  
- Real-time filtering based on user input  

---

## Working Principle
- User enters book details and clicks "Add Book"  
- Book is stored in an array  
- List is re-rendered dynamically  
- Search filters the displayed books  
- Remove deletes a book from the array and updates UI

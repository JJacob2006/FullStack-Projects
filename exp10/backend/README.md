# Backend

Express.js server for the full-stack application.

## Getting Started

Install dependencies:
```bash
npm install
```

Start the server:
```bash
npm start
```

## Configuration

The server runs on the port specified in the environment or defaults to port 5000.

## API Endpoints

Define your API routes and endpoints in `server.js`.

## Technologies

- Node.js
- Express.js

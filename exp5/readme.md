## Overview

This is a full-stack web application experiment built with Node.js and Express.js to demonstrate middleware functionality, including authentication and logging mechanisms. The application connects to a MySQL database for data persistence and uses environment variables for secure configuration management. It implements custom middleware for request logging and token-based authentication.

## Tools & Technologies

- **Node.js** - JavaScript runtime
- **Express.js** - Web framework
- **MySQL** - Relational database
- **dotenv** - Environment variable management

## Project Structure

- `server.js` - Main server file
- `package.json` - Project dependencies and configuration

## Getting Started

Install dependencies:
```bash
npm install
```

Start the server:
```bash
npm start
```
